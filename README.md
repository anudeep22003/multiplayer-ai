# Multiplayer AI 


I have a simple use case that I havent found an easy solution to. When I am on a call with a friend and we are discussing something, i want a common thread that we can both see, can send in messages to and then trigger the AI. Effectively collaborative AI. The focus is on making the experience as easy as possible. Excalidraw is an inspiration, where they make it dead simple to create a room and invite users to interact with the same whiteboard. 

That is what this project aims to be.

Here are some goals:
- Make as easy as possible for anybody to self-host this
- Serverless first architecture, I or anybody running this should not be incurring any costs to run this unless it is actually doing work
- Social first, make using AI with friends fun and useful
- Optimize UX for a great multiplayer experience, dont shy away from using tech to accomplish that (example: Websockets)
- Start simple and boring, and slowly add complexity
- Build features iteratively, don't final version this on day 1
- Move forward always, explore at every step
